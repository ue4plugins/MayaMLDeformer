Documentation for Maya ML Deformer Plugin can be found on our site:
https://dev.epicgames.com/documentation/en-us/unreal-engine/how-to-use-the-machine-learning-deformer-in-unreal-engine?application_version=5.5


To install copy all the files in the Source directory to your maya/modules folder: The .mod file and MLDeformer folder should both appear inside the modules director. 

(Windows)
    C:\Users\<username>\Documents\maya\modules
	--- or ---
    C:\Users\<username>\Documents\maya\<version>\modules
(MacOS)
    ~/maya/modules
	--- or ---
    ~/maya/<version>/modules
(Linux)
    ~/maya/modules
	--- or ---
    ~/maya/<version>/modules
